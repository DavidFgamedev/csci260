Game Overview & Instructions

Phantoma · Unity prototype build

What It Is

Phantoma is a multiplayer social hub world built around expressive characters and a shared explorable space. It's a place to be more than a place to beat — closer in spirit to PlayStation Home or a small MMO lobby than a combat game.

Controls

  • Move — W A S D
  • Look — Mouse
  • Jump — Space
  • Sprint — Left Shift
  • Emote — E
  • Chat — Enter

Goal

There is no win condition. Progression comes from exploration, expression, and finding hidden corners of the hub. The Phase 1 draft build includes the hub environment, a rigged playable character (Drippy), and the core movement system.

Source Code Breakdown

Approximately 340 lines of C# written by me for the Unity prototype. My code is primarily in:

  • PlayerController.cs — movement, camera control, input handling (~140 lines)
  • HubManager.cs — spawn logic, scene state (~80 lines)
  • EmoteSystem.cs — emote playback and input wiring (~60 lines)
  • CharacterAnimator.cs — state machine driver (~60 lines)
